# DSA Quest

**A Java-Based Data Structures and Algorithms Quiz Application**

## 1. Project Description

DSA Quest is a desktop-based quiz application developed using Java. It is designed to help students learn and test their knowledge of Data Structures and Algorithms (DSA) through an interactive quiz interface.

The application provides different quiz topics and difficulty levels to make learning more engaging while allowing users to monitor their quiz performance.

## 2. Project Objectives

- To help students understand and review Data Structures and Algorithms.
- To provide an interactive platform for practicing DSA concepts.
- To test users' knowledge through quizzes.
- To track quiz performance and progress.

## 3. Features and Functionalities

- **Topic Selection** – Allows users to select a DSA topic.
- **Difficulty Selection** – Provides different difficulty levels.
- **Interactive Quiz** – Displays questions for users to answer.
- **Score Tracking** – Keeps track of the user's quiz score.
- **Progress Tracking** – Displays the user's quiz progress.
- **Timer** – Tracks the time spent during the quiz.
- **Accuracy Tracking** – Displays quiz answer accuracy.
- **Streak Tracking** – Monitors consecutive correct answers.

*Note: These features should match the functionalities implemented in the final application.*

## 6. How to Run the Application

1. Install the Java Development Kit (JDK).
2. Clone or download this GitHub repository.
3. Open the project folder in Visual Studio Code.
4. Make sure the Java source files are available.
5. Compile the Java source code.
6. Run the application.

If the project uses a single Java source file, you can use:

```bash
javac DSAQuest.java
java DSAQuest
```
